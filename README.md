# 🥟 상하이 여행 2027 플래너

용준 · 민혜 · 다정 셋이 같이 쓰는 상하이 여행 계획 웹앱 (2027.2.26 – 3.1, 3박 4일).
빌드 과정 없는 순수 HTML/JS라서 GitHub Pages에 올리면 끝이에요.

## 기능

| 탭 | 하는 일 |
|---|---|
| 🗓️ 일정 | 4일 시간표. 빈 칸 클릭 → 추가, 블록 끌어서 이동(다른 날로도), 아래 모서리로 시간 조절. 목록 보기에는 일정 사이 **이동시간·거리·고덕 길찾기**가 나오고, 이동시간이 부족하면 ⚠️ 표시 |
| 💾 저장함 · 🧹 비우기 | 시간표를 통째로 **최대 10개**까지 저장·불러오기·덮어쓰기. 하루/전체/추천 일정만 비우기(항공·숙소 유지, 비우기 전 자동저장). ☑️ 골라서 여러 개 삭제. 모두 10초 안에 되돌리기 |
| ✨ 추천 일정 | 속도·관심사·디즈니/주자자오 여부를 고르면 **빈 시간만** 동선(실제 거리 기준)에 맞춰 채움. 월요일 휴관 장소는 피함. 미리보기에서 골라서 적용 |
| 🗺️ 지도 | 고덕지도(중국 좌표계 GCJ-02) 위에 날짜별 번호 핀과 동선. 숙소·찜한 곳·추천 장소 함께 표시. 쑤저우·저우좡·항저우 같은 근교까지. 핀을 끌어서 위치 보정 가능. **장소 검색**(中文·English·한국어) → 바로 일정에 넣기/찜/택시카드 |
| 💡 가고싶은 곳 | 유튜브·샤오홍슈·블로그 링크를 모으고 셋이 ❤️ 투표 → 일정에 넣기. 유튜브는 앱 안에서 바로 재생. 상하이 장소 40여 곳 라이브러리 포함 |
| 🏨 숙소 | 날짜·인원이 채워진 Trip.com 검색 버튼. 예약확인 메일을 붙여넣으면 이름·날짜·예약번호·주소·금액 자동 입력 → 일정표에 체크인/체크아웃 자동 표시 |
| 💰 경비 | 위안/원 지출 기록, 환율 자동 갱신, 누가 누구에게 얼마 보낼지 정산 |
| ✅ 준비 | 항공편, 준비물 체크리스트(누가 체크했는지 표시), 현지 꿀팁 |
| ⚙️ 설정 | 공유 링크, JSON 백업/복원, 캘린더(.ics) 내보내기 |

그 밖에: 👥 **마지막 접속 시간**(헤더 이름 아래), 🚕 **택시카드**(중국어 목적지를 크게 띄워 기사님께 보여주기), 일정마다 고덕/바이두/구글 지도 링크, 되돌리기, 휴대폰 홈 화면에 추가 가능.

### 왜 고덕지도?
중국 지도는 법적으로 GCJ-02 좌표계를 써서, 구글 지도의 위성사진과 도로가 수백 m 어긋나요.
이 앱은 기본으로 고덕(AutoNavi) 타일을 쓰고 좌표도 GCJ-02로 저장해서 핀이 정확히 맞아요.
OpenStreetMap 레이어를 고르면 자동으로 좌표를 변환해서 보여줘요.
지도 검색은 기본으로 OpenStreetMap(Nominatim·Photon) 데이터를 써요. 고덕 개방플랫폼의 Web服务 키를 ⚙️ 설정에 넣으면 고덕 POI 검색으로 바뀌어요.
※ 기본 장소 좌표는 대략치라서, 어긋난 핀은 지도 탭의 “✋ 핀 옮기기”로 맞춰주세요.

## 1. GitHub Pages로 무료 배포

```bash
gh auth login
gh repo create shanghai-2027 --public --source . --push
gh api -X POST repos/{owner}/shanghai-2027/pages -f "source[branch]=main" -f "source[path]=/"
```

몇 분 뒤 `https://<깃허브아이디>.github.io/shanghai-2027/` 에서 열려요.
(웹에서 하려면: 저장소 → Settings → Pages → Branch `main` / `/(root)` → Save)

## 2. 셋이 실시간으로 같이 편집하기 (Firebase, 무료 · 약 5분)

Firebase 설정 전에는 **각자 브라우저에만** 저장돼요.

1. https://console.firebase.google.com → **프로젝트 추가** (이름 예: `shanghai-2027`, 애널리틱스 꺼도 됨)
2. 왼쪽 **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**
3. Firestore **규칙** 탭에 이 저장소의 `firestore.rules` 내용을 붙여넣고 **게시**
4. 프로젝트 설정(⚙️) → **내 앱 → 웹(</>)** 추가 → 나오는 `firebaseConfig` 값을 `firebase-config.js`에 붙여넣기
5. 커밋·푸시 → 사이트 새로고침하면 오른쪽 위가 🟢 **공유 중**
6. ⚙️ 설정 탭의 **링크 복사** → 민혜·다정에게 카톡으로 전송 (링크 끝 `#t=…`가 우리 여행방 비밀키)

> Firebase 웹 설정값은 공개돼도 괜찮은 값이에요. 데이터는 비밀키 링크를 아는 사람만 읽고 쓸 수 있어요.

## 3. 중국 현지에서 쓸 때

- 중국에서는 Google(Firebase)·YouTube가 막혀요. **한국 통신사 로밍**이나 **홍콩/글로벌 eSIM**을 쓰면 그대로 동작해요.
- 연결이 끊겨도 마지막으로 불러온 일정은 보이고, 수정한 내용은 연결되면 자동으로 올라가요.
- 출발 전에 ⚙️ → **JSON 내보내기**로 백업해두면 안심.
